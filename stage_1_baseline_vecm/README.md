# Stage 1 — Baseline Nominal VECM

This stage contains the EViews code for the baseline nominal analysis.

## File

`stage_1_baseline_vecm.prg`

## Main Tasks

- Data preparation within EViews
- ADF unit-root tests
- VAR lag selection
- Five-variable and four-variable VECM estimation
- Johansen cointegration tests
- Model diagnostics
- Cholesky IRFs and FEVDs
- Construction of the error-correction term
- Full-sample predictive regressions

## Software

EViews
