# Stage 2 — Rank and Restriction Inference

This stage contains the Python code for supplementary inference and robustness analysis of the baseline VECM framework.

## File

`stage_2_rank_and_restriction_inference.py`

## Main Tasks

- ADF and Zivot–Andrews unit-root tests
- VAR lag-selection audit
- Johansen rank inference
- Reinsel–Ahn finite-sample correction
- Wild-bootstrap rank inference
- Likelihood-ratio restriction tests
- Long-run membership, weak-exogeneity, and homogeneity tests
- Disequilibrium-index construction
- Recursive and robustness analyses

## Data

Uses the common monthly analysis dataset provided in the repository's `data/` directory.
